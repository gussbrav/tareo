Detalle

¿Qué incluye la implementación?

Setup one-time (pago único al firmar)

1. Instalación técnica
  • Puesta en producción del sistema
  • Configuración de base de datos y hosting
  • Certificado SSL y backups automáticos
  • Verificación de disponibilidad 24/7
2. Configuración de marca
  • Logo, favicon y colores corporativos
  • Nombre y datos fiscales de la empresa
  • Personalización del correo de Excel
  • Etiqueta de ambiente (producción/staging)
3. Carga inicial de datos
  • Importación del catálogo de CECOs desde Excel
  • Alta de trabajadores (bulk desde plantilla)
  • Creación de usuarios con roles asignados
  • Configuración de proyectos activos
4. Capacitación al equipo
  • Sesión con administradores (1-2 horas)
  • Sesión con supervisores (1 hora)
  • Video-guía para trabajadores en la obra
  • Manual de usuario en PDF

Suscripción mensual (recurrente)

Infraestructura
  • Hosting cloud en servidores de alta disponibilidad
  • Base de datos PostgreSQL con backups diarios
  • SSL/HTTPS y protección contra intrusiones
  • Monitoreo 24/7 del servicio
Producto
  • Panel web completo (dashboard, agenda, tareo, admin)
  • Aplicación móvil Android para el equipo de campo
  • Actualizaciones automáticas de nuevas versiones
  • Nuevas funcionalidades incluidas sin costo extra
Soporte
  • Consultas por email (contacto@azoramind.com)
  • Tiempo de respuesta según plan (12 h / 24 h / 48 h)
  • Reporte y corrección de bugs sin cargo
  • Asistencia con importaciones y cambios de catálogo
Escalabilidad
  • Sube o baja de plan cuando lo necesites
  • Sin límite en volumen de actividades registradas
  • Datos históricos disponibles durante la vigencia del contrato
  • Exportación de datos disponible en cualquier momento
